# KAMO LIFE｜加茂市移住相談Webアプリ

加茂市に特化した、スマートフォン対応の移住相談PWAです。

## 主な機能
- 加茂暮らし相性診断
- 住宅取得補助金の簡易条件チェック
- 支援制度、住まい、仕事、子育て、交通情報
- 月々の生活費シミュレーター
- OpenStreetMap地図表示
- 相談メモ保存、加茂市政策推進課宛てメール作成
- PWA対応（ホーム画面追加・オフライン表示）

## GitHub Pagesへの公開
1. リポジトリを作成
2. このフォルダ内の7ファイルをアップロード
3. Settings → Pages → Deploy from a branch → main / root → Save

## 注意
非公式の試作アプリです。制度は年度・予算・申請時期等で変更されるため、利用前に加茂市公式サイトで最新情報をご確認ください。
