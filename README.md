# お試し移住ナビ Plus Ver.2

GitHub Pagesで動作する自治体提案用デモアプリです。

## 追加機能
- お試し住宅検索
- Google Maps埋め込み
- 最寄駅・交通アクセス
- 家賃・生活費シミュレーター
- 移住支援金・補助金検索
- 写真・動画風地域紹介
- お気に入り保存
- 質問形式の自治体診断
- おすすめ滞在プラン
- 日本語・英語・中国語切替
- ブラウザ保存型マイページ
- PWA・オフライン対応

## 更新方法
現在のGitHubリポジトリ内の古いファイルを、このZIP内のファイルで置き換えてください。
GitHub Desktopでコミット後、Push originを押すと公開ページが更新されます。

## 注意
Google Mapsは検索結果の埋め込み表示です。自治体データ、補助金、施設情報はデモ用です。
実運用では最新の公式データ確認、利用規約、プライバシーポリシー、管理画面、データベースが必要です。
